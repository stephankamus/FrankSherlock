# v0.9.0

Primeira versão numerada deste fork. O número sobe de `0.8.2` (upstream) para `0.9.0`
para deixar claro que o binário não é o release do repositório de origem.

## PT-BR

### Cliente web (novo)

- Cliente web somente leitura (PWA) sobre um snapshot imutável publicado pelo desktop,
  com busca, filtros, ordenação, scroll infinito, sidebar de raízes/subdiretórios/álbuns,
  rostos, duplicados informativos e preview de imagem, vídeo (Range) e PDF.
- **Tela de login por token**: não é mais necessário colar o token na URL. O cliente
  valida o `AUTH_TOKEN` antes de armazená-lo, guarda no `localStorage` e volta ao login
  quando a API responde `401`. Links com `?token=` continuam funcionando no primeiro acesso.
- **Preview corrigido**: clicar em uma foto abre exatamente aquela foto, com navegação
  anterior/próxima; as visões de comparação (duplicados e fotos de uma pessoa) continuam
  em grade.
- Publicação atômica com revisões, ponteiro `current.json`, sincronização incremental de
  miniaturas/crops e poda de revisões antigas.
- Container Docker não-root, filesystem read-only, healthcheck e mapeamento explícito de
  roots por `media.map.json`.

### Desempenho e bibliotecas grandes

- Pipeline de scan com **um decode por foto** produzindo a miniatura de 300 px e o JPEG
  de 1024 px da visão.
- Backlog com produtor de CPU e consumidor de GPU para reduzir a ociosidade.
- Request de visão mais barato: downscale, `num_ctx` derivado da imagem, prompt curto
  com `format: json` e gate de OCR.
- Cache de miniaturas por raiz (`<root_key>/<rel_path>`), com migração, validação sem
  mtime do SMB, auto-cura e deduplicação por dHash/fingerprint.
- Botões **Repair Thumbnails** e **Compact DB** para bibliotecas grandes em share.
- Endurecimento de shares: raízes offline, relink (`Locate…`), recusa de scan com
  descoberta zerada e compactação do banco.

### Funcionalidades e correções

- Fotos ocultas com filtro no desktop e invisibilidade garantida no web.
- Conversão opt-in de HEIC/NEF para JPEG ao lado dos originais.
- Descrições em PT-BR (com conversão das existentes) e tela de Settings do pipeline.
- Visualizador de logs ao vivo, prompt de retomada ao abrir pasta já indexada e ETA da
  fila de classificação.
- Detecção de rostos dentro do scan, com agrupamento, nomes e busca `face:`.
- Botão de ocultar foto não é mais bloqueado pela descrição no hover; o contador de
  rostos ganhou tooltip e fica acima do overlay.
- Botão **Check for Updates** oculto para impedir que um release do upstream sobrescreva
  as mudanças locais. O plugin do updater permanece no código.

## EN-US

### Web client (new)

- Read-only web client (PWA) over an immutable snapshot published by the desktop, with
  search, filters, sorting, infinite scroll, a sidebar with roots/subdirectories/albums,
  faces, informative duplicates, and image, video (Range) and PDF preview.
- **Token login screen**: pasting the token into the URL is no longer required. The client
  validates `AUTH_TOKEN` before storing it, keeps it in `localStorage`, and returns to the
  login form when the API answers `401`. `?token=` links still work for the first visit.
- **Preview fixed**: clicking a photo opens exactly that photo, with previous/next
  navigation; comparison views (duplicates and a person's photos) still use a grid.
- Atomic publishing with revisions, a `current.json` pointer, incremental thumbnail/crop
  sync and pruning of old revisions.
- Non-root Docker image, read-only filesystem, healthcheck and explicit root mapping via
  `media.map.json`.

### Performance and large libraries

- Scan pipeline with **one decode per photo** producing both the 300px thumbnail and the
  1024px vision JPEG.
- Backlog with a CPU producer and a GPU consumer to reduce idle time.
- Cheaper vision request: downscale, image-derived `num_ctx`, short prompt with
  `format: json`, and an OCR gate.
- Per-root thumbnail cache (`<root_key>/<rel_path>`) with migration, SMB-mtime-independent
  validation, self-healing and dHash/fingerprint deduplication.
- **Repair Thumbnails** and **Compact DB** buttons for large libraries on a share.
- Share hardening: offline roots, relink (`Locate…`), refusal to scan when discovery
  collapses to zero files, and database compaction.

### Features and fixes

- Hidden photos with a desktop filter and guaranteed invisibility on the web.
- Opt-in HEIC/NEF to JPEG conversion next to the originals.
- PT-BR descriptions (with conversion of existing rows) and a pipeline Settings screen.
- Live log viewer, startup prompt for an already indexed folder, and an ETA for the
  classification queue.
- Face detection inside the scan, with clustering, names and `face:` search.
- The hide-photo button is no longer blocked by the hover description; the face count
  badge gained a tooltip and paints above the overlay.
- The **Check for Updates** button is hidden to prevent an upstream release from
  overwriting local changes. The updater plugin stays in the code.
